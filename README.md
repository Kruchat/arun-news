# อรุณ / ARUN

ฉบับเช้า — เว็บอ่านข่าวแนวหนังสือพิมพ์ รวบรวมข่าวไทยและโลกจากฟีดสาธารณะ

**The dawn briefing.** An editorial news reader for Bangkok mornings: Thai and world wires, a five-story brief, saved articles, and a day/night edition.

## สิ่งที่ทำได้

- ข่าวสดจาก BBC Thai, ไทยรัฐ, The Standard, BBC, The Guardian, Al Jazeera, Hacker News
- หมวด: ไทย · โลก · เทคโนโลยี · ธุรกิจ · กีฬา · วัฒนธรรม · วิทยาศาสตร์
- ฉบับเช้า 5 เรื่องก่อนเริ่มวัน
- ค้นหา · เก็บไว้อ่านทีหลัง (แขกบันท้องถิ่น / ซิงก์เมื่อเข้าสู่ระบบ)
- สลับภาษาไทย/อังกฤษ · ฉบับกลางวัน / ฉบับค่ำ
- วันที่และเวลาตามกรุงเทพฯ (พ.ศ.)

## Stack

React 19 · TypeScript · TanStack Start · Tailwind v4 · Better Auth

ข่าวถูกดึงจาก RSS สาธารณะ ไม่ต้องใช้ API key ทุกเรื่องลิงก์กลับไปต้นฉบับ
